# Walkthrough - Tennis Bracket UX Flow Reordering & Dynamic Scheduling Upgrades

이 문서는 테니스 대진표 앱(`tennis-match`)의 설정 화면 UX 흐름 재배치, 참석 투표 활성화 연동, 그리고 세부 복식 게임 유형(남복/혼복/잡복) 지정 스케줄링 고도화에 대한 최종 결과 명세서입니다.

---

## 🛠️ 작업 및 개선 사항

### 1. 입력 흐름 재배치 (UX 개편 완료)
대진 생성 전 입력 데이터의 인과관계와 데이터 의존성을 완전히 해소하기 위해 입력 절차를 아래와 같이 **5단계**로 나누어 배치 완료했습니다:
1. **1단계: 경기 날짜 선택**: 경기가 진행될 날짜를 지정합니다.
2. **2단계: 참가자 선택**: 투표 목록을 불러오거나 회원 명단에서 오늘 참여할 인원을 추가/제외합니다.
3. **3단계: 경기 세부 설정**: 총 경기 수 산출을 위한 라운드/코트 수와 더불어 남복/혼복/잡복 복식 유형 세부 게임 수 및 시작/종료 시간을 정합니다.
4. **4단계: 참가자 목표 게임수 설정 및 균등 배분**: 3단계에서 정한 총 슬롯 수(`라운드 × 코트 × 4`)를 기준으로, 참여할 참가자 명단에 목표 게임수를 균등하게 분배합니다. **[목표 게임수 자동 균등배분]** 버튼을 통해 간편하게 숫자를 맞출 수 있습니다.
5. **최종 단계: 대진표 생성**: 모든 조건이 완벽히 만족된 상태에서 자동으로 최적 대진을 생성합니다.

### 2. 참석 투표 불러오기 버튼 동적 연동
- 선택된 경기 날짜에 진행 중이거나 마감된 참석 투표(`matchedEvent` 데이터)가 존재할 경우에만 `🗓️ 참석 투표 불러오기 (참석 N명)` 버튼이 **활성화(Enabled)**됩니다.
- 투표 내역이 없는 날짜인 경우 버튼이 **비활성화(Disabled - 투표 없음)** 상태로 즉시 반응하여, 불필요하게 투표 불러오기를 눌러서 에러 경고를 마주치지 않도록 안전 가드를 추가했습니다.

### 3. 세부 복식 게임 수(남복/혼복/잡복) 조건 지정 및 스케줄러 알고리즘 업그레이드
- **복식 유형 세부 지정**: 기존 `혼복 게임 수` 인풋 외에 **남복 게임 수** 및 **잡복 게임 수** 인풋을 추가 제공합니다.
- **실시간 게임 수 검증**: 설정한 `남복 + 혼복 + 잡복` 게임 수의 합계가 총 경기 수(`라운드 수 × 코트 수`)와 완벽히 맞아떨어지는지 실시간으로 수학적 검증을 하여 문구와 배지 색상으로 알려줍니다. 합계가 일치하지 않으면 자동 생성 버튼이 비활성화됩니다.
- **스케줄러 고도화 ([scheduler.js](file:///C:/Users/LGHV/.gemini/antigravity/scratch/tennis-app/lib/scheduler.js))**:
  - **남복 (Men's Doubles)**: 순수 남성(M)으로만 구성된 4인 조합 매치 생성.
  - **혼복 (Mixed Doubles)**: 남성 2명, 여성 2명으로 구성된 매치 생성.
  - **잡복 (Joint Doubles)**: 남복이나 혼복 유형을 제외한 혼합 조합(여성 복식 4F, 여3 남1, 남3 여1 등 여성 회원이 적어도 1명 이상 참가하는 조합)을 무작위 및 필요도 가중치 기반으로 매칭하여 생성합니다.
